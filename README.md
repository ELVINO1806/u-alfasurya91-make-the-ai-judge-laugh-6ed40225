## Entry

Our team building exercise was trust falls. I fell, nobody caught me, and HR called it a lesson in self-reliance.

A one-line office joke: the classic trust-fall exercise goes wrong, and HR reframes the failure as a lesson instead of an accident.

## Why it works

The joke lands on a relatable workplace moment — everyone has sat through a trust exercise — and the punchline flips the blame: instead of apologising, HR turns a dropped colleague into a teachable moment about self-reliance.

## How to run

```bash
python3 main.py
```

This writes the entry text, exactly as shown above and nothing else, to `/output/entry.txt`. The program uses only the Python standard library and needs no extra setup.
